# 技术方案检查清单

[分布式设计](interview_design.md) · [一致性与平台设计](topics/distributed-systems.md)

## 从约束推导方案

| 检查点 | 需要给出明确答案 |
| --- | --- |
| 数据归属 | 谁是权威源，业务键与数据粒度是什么 |
| 状态与并发 | 哪些转换合法，如何阻止覆盖与重复 |
| 一致性 | 哪些数据必须同事务提交，哪些可以延迟完成 |
| 失败与重试 | 超时是否可能已成功，重试键和恢复入口是什么 |
| 资源 | 峰值输入、并发、队列、扫描量和下游上限是什么 |
| 权限 | 哪个可信入口强制校验身份、数据范围与审计 |
| 观测 | 如何用请求号、事件号、任务实例和业务键定位问题 |
| 变更 | 如何兼容、灰度、回退，以及核对迁移数据 |

扩展性建立在已知变化点上。先给出最小可用实现和可观测的成功条件，再讨论拆分与扩容，避免用组件数量代替方案可行性。
