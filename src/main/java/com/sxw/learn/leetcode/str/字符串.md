# 字符串

a的ASCII码是97，ASCII码表中，小写字母排在大写字母的后面，
一个字母的大小写数值相差32，一般知道大写字母的ASCII码数值，
其对应的小写字母的ASCII码数值就算出来了，是大写字母的ASCII码数值+32。
由于A的ASCII码是65，因此a的ASCII码是97
